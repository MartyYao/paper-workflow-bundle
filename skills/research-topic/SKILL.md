# Research Topic

> Version: v0.2.0（研究发现与文献版图重构版）

## 定位：研究发现工具，不是候选题打分器

本技能承担论文阶段 0 的研究发现、文献查新、空白诊断和选题压缩；`paper-workflow` 只负责读取项目状态、调用本技能、检查成果物和推进阶段。

本技能必须主动带着研究者完成以下思维链条：

```text
既有研究积累与现实观察
  → 大问题重构
  → 研究版图：人们已经研究了什么
  → 空白清单：还不知道什么
  → 空白成因：为什么还没有人做
  → 研究谜题与多条路径
  → 一个政府行为 X + 一个企业结果 Y
  → 文献碰撞、数据/识别审计
  → GO / HOLD / KILL
```

用户没有提出成熟想法时，本技能也必须基于研究者既有论文、现实问题和文献版图主动生成研究谜题，不能把“请你再想几个方向”当作选题工作的主要内容。不能先列几个标题，再用少量搜索结果为标题找理由。

## 固定研究边界

除非用户明确修改发表层次或研究范围，以下核心护栏不可被用户一句话绕开；如果用户要求放弃这些护栏，应退出本技能的公司金融实证选题模式，而不是继续生成一个不合格题目：

1. 研究对象是企业或企业行为，结果变量 `Y` 必须能够在企业层面观测；
2. 核心解释变量 `X` 是政府行为、政府政策、政府制度安排或可明确识别的政府诱发冲击；房地产下行、AI 浪潮、K 型分化、财政压力等宏观状态默认是背景或暴露条件，不能未经转换直接冒充政府行为 `X`；
3. 主问题只保留一个核心 `X` 和一个核心 `Y`。就业、创新、分红、投资、融资成本等不能被拼成复合因变量；
4. 机制变量解释 `X → Y`，不能把机制本身伪装成论文结论；
5. “未定位到”只表示在明确的检索边界内未定位到，不得写成“没有人研究”；
6. 空白必须先经过“为什么没有被做”的诊断。数据不可得、识别不能成立、制度冲击太新或结果变量没有经济含义的方向，应当被识别为死胡同或 `HOLD`，而不是被包装成创新。

## 三种工作模式

### 探索模式（新论文、新方向的默认模式）

按“重构问题 → 文献版图 → 空白成因 → 研究启发 → X/Y 压缩”推进。没有完成文献版图和空白成因诊断前，不生成 3—5 个貌似确定的题目，也不作 `GO` 判断。

### 审计模式（用户已经给出明确 X/Y 或候选题）

只有当用户同时给出一个政府行为 `X`、一个企业层面 `Y`、行为主体、政策/行为时点和处理变异时，才进入审计模式。仅有宏观背景、政策领域、现实观察或“研究国企社会责任”，仍然进入探索模式。审计模式直接做精确碰撞检索、邻近文献检索、空白成因诊断和可行性审计；仍须报告“这个题目位于哪一个研究分支、该分支已有何种共识、它为什么尚未被完成”。

### 决策模式（候选方向已形成）

把候选方向放入同一张比较矩阵，逐项比较研究价值、文献碰撞、X/Y 清晰度、数据、识别、执行成本和失败后的剩余知识，输出 `GO / HOLD / KILL`。分数不能替代证据和研究者判断。

## 与 paper-workflow 的接口

### 输入

先读取：

1. `研究/<项目名>/论文写作/00-项目仪表盘.md`（若已存在）；
2. `研究/<项目名>/论文写作/01-选题/` 中已有短名单、淘汰记录、研究计划和检索记录；
3. 用户已发表论文、博士论文、当前研究方向、数据资产和发表边界；
4. `agent memory/学术/_设计/` 中与选题直接相关的设计经验；
5. 若由 `research-discovery` 回退而来，读取对应的发现文件和 `研究发现/03-选题孵化.md`。

不要把用户提出的宏大叙事直接当作 `X`、`Y` 或机制。先拆成观察、制度变化、政府选择、企业决策、结果变量、机制和可估计的因果命题。

在 `研究/<项目名>/论文写作/01-选题/` 生成或更新以下成果物。探索模式先在对话中交付结构化报告，再按项目状态落库；没有项目名时不得擅自写入 Obsidian vault。

| 成果物 | 必须回答的问题 |

| `选题检索边界.md` | 检索日期、数据库、关键词、筛选标准、覆盖限制是什么？ |
| `文献全景地图.md` | 这个领域分成哪些研究分支，每个分支谁研究了什么？ |

| `研究计划.md` | 仅在用户确认 `GO` 后，阶段 1—5 的权威入口是什么？ |

## 工作流程

### 0. 重构研究者的研究主线和“大问题”

先用用户既有工作归纳稳定的研究主线，至少写出：政府做了什么、企业改变了什么、改变为什么重要。然后把新观察放入以下四层，而不是立即寻找变量名：

```text
现实事实：社会或企业发生了什么？
制度矛盾：政府的目标、责任或权力边界发生了什么变化？
企业边际：企业哪一个决策最直接地承接了这种变化？
可估计命题：一个政府行为 X 是否改变企业结果 Y？
```

本步骤的交付必须包括：

- 研究者的既有研究脊梁，以及新题目与旧论文的连续性和差异；
- 用户真正关心的大问题，用一段话准确复述；
- 至少两种将大问题压缩到企业行为的可能方式；
- 背景、解释变量、因变量、机制和政策含义的初步区分；
- 当前不应急于决定的地方，以及接下来需要用文献查明的分歧。

### 1. 先建立“研究问题版图”，再生成题目

围绕大问题建立至少 4 个研究分支。公司金融与政府行为题目至少交叉检索以下四组：

| 交叉方向 | 目的 |
|---|---|
| 同一政府行为 × 不同企业结果 | 找出该政策已经影响了哪些企业决策，避免重复既有 Y |
| 同一企业结果 × 不同政府行为 | 找到企业层面结果背后的新政府解释 |
| 同一机制 × 不同制度/政府层级 | 判断机制是否具有制度外部有效性 |
| 同一现实问题 × 不同政府工具 | 将宏观叙事转换为财政、监管、产权、信用、考核或资源配置行为 |

每个分支必须回答：研究对象、政府行为、企业结果、机制、样本、时间、识别方法、主要结论、结论边界和代表性来源。版图不是论文罗列，而要明确标注：

- `共识`：多篇研究方向一致的结论；
- `争议`：研究结论冲突或机制解释不同；
- `边界`：只在特定企业、地区、时期或政策层级成立；
- `未定位到`：在本次检索式、数据库、年份和语言范围内未找到直接研究；
- `未知`：检索证据不足，不能作空白判断。

不要因为一个关键词搜不到结果就认定空白。先换同义词、制度名称、结果变量的经济含义、英文表达、政府层级和研究方法，再判断覆盖是否足够。

### 2. 文献检索必须形成“证据全景”，不是关键词摘录

按 `references/evidence-search-protocol.md` 和 `references/exploration-and-gap-diagnosis.md` 执行。新方向采用“两阶段证据配额”，避免在 X/Y 尚未形成时机械凑精确文献：

- 至少 4 个研究分支；
- 探索初筛：每个分支至少 3 篇独立学术文献，尽量包含至少 1 篇中文和 1 篇英文，并在分支层面至少有 1 篇挑战/限定性研究；此阶段允许精确文献为 0，但必须标记 `UNKNOWN` 或“在当前边界内未定位到”；
- 优先路径审计：进入候选短名单前，对优先分支扩展到 5—8 篇代表性学术文献，包含精确文献、邻近文献、近期文献和挑战/限定性研究；如果精确文献为 0，必须明确记录为“精确空白”，不能用邻近文献冒充；
- 中文和英文均须覆盖；中文至少覆盖核心期刊、学位论文或高质量工作论文中的可获得证据，英文至少覆盖正式发表论文和可识别的工作论文；
- 现实政策驱动的题目至少纳入 2 条权威政策/官方文件，但政策材料不能替代学术文献；
- 每条关键文献记录完整书目信息、DOI/URL（如有）、研究问题、X、Y、机制、样本、识别、结论、限制、证据角色和全文状态；
- 对重要结论优先回到论文、期刊官网、作者版本或权威数据库页面，不以搜索摘要或二手转述作为唯一证据；
- 记录每次检索的日期、平台、完整查询式、过滤条件、结果数量或覆盖范围、纳入/排除理由和仍未解决的不确定性。

检索报告必须给出“已覆盖的研究空间”而不是只给出若干引用。若工具、数据库或全文权限受限，要报告受限位置及其对空白判断的影响。

### 3. 建立“空白—成因”诊断，而不是把空白自动当贡献

对每一个研究分支填写：

```text
已有共识 → 未决问题 → 空白类型 → 为什么仍未被做 → 这是否是可克服的障碍
         → 可以回答的最小经验问题 → 若不能克服，如何 HOLD/KILL
```

空白成因至少按以下类别诊断：

| 空白成因 | 典型表现 | 对选题的含义 |
|---|---|---|
| 数据空白 | X/Y 无公开口径、企业匹配成本高、文本/交易数据不稳定 | 先做可得性和小样本试采，不因“没人做”直接 GO |
| 制度/时点空白 | 政策太新、政府层级不同、制度只在少数地区存在 | 可能是新贡献，但要有足够处理后期和可比对照 |
| 识别空白 | 政府行为与企业特征共同决定，缺乏外生变异 | 需要新的政策冲击、工具变量或边界设计；否则是死空白 |
| 概念空白 | 同一术语在不同文献中代表不同经济含义 | 先统一定义，可能形成测量贡献，也可能只是命名差异 |
| 聚合层级空白 | 现有研究在地区/行业层面，企业行为无法直接推出 | 只有在企业暴露或政策传导可识别时才有微观贡献 |
| 结果变量空白 | 没有人研究某个 Y，但 Y 与政府行为关系不直接或经济含义弱 | 通常不能仅靠换 Y 形成贡献 |
| 文献拥挤 | X、Y、机制和制度已被多次验证 | 必须改变核心问题或 KILL，不靠换样本、换指标伪创新 |
| 死胡同 | 研究问题本身是机制、结论过于直接、政策效果没有企业边际 | 记录原因，避免在后续会话重复孵化 |

“为什么没有人做”必须有证据或可验证推断。将“尚未定位到”与“因果关系无法识别”严格分开；将“数据难”与“理论不重要”严格分开；将“政策新”与“已经产生可估计变异”严格分开。

### 4. 从文献版图主动生成研究谜题

完成版图和成因诊断后，至少生成 3—5 个“研究谜题”，先写谜题再写题目。每个谜题必须包括：

1. 大问题：它回应哪个现实和制度矛盾；
2. 文献事实：哪些研究已经知道什么；
3. 冲突或未知：已有结论在哪一处不能解释现象；
4. 政府边际：政府究竟采取了什么行为，而不是泛泛的“财政压力/经济转型”；
5. 企业边际：哪一个企业决策最直接、最单一地承接该行为；
6. `X` 候选、`Y` 候选和最小机制；
7. 如果结果为正、不显著或反向，分别会更新什么认识；
8. 该路径最可能因数据、识别、制度时点还是贡献不足而失败。

允许从同一个大问题沿不同政府—企业接口展开，例如：政府信用边界、产权与控制、企业融资条件、投资/资产配置、创新投入质量、分红与资本索取、政策资源配置、空间资本流动。每条路径必须回到一个企业层面结果，不能把多个社会目标拼成复合 Y。

本步骤的职责是给研究者“有证据的启发”，不是要求研究者先替工具提出方向。报告应说明每条路径是由哪一组文献和哪个未决问题推导出来的。

### 5. 把研究谜题压缩为一个明确 X 和一个明确 Y

使用以下句式逐一检验：

> 某项可识别的政府行为/政策冲击 `X`，是否改变企业的单一决策或结果 `Y`？在什么制度条件下，为什么？

`X` 必须说明：行为主体、政策层级、出台/执行时点、作用对象、处理变异和可识别来源。财政压力可以是解释条件或变量，但只有在它对应明确的政府行动、制度反应或可辩护的外生冲击时，才可作为核心 `X`。

`Y` 必须说明：企业层面经济含义、数据库或原始数据来源、单一测量口径、与 `X` 的时间顺序以及它为何是政府行为影响企业的直接边际。将“就业+创新+分红+民生责任”列为 Y，或把“国企承担社会使命”列为 Y，均不合格。

`M` 只保留最必要的传导机制。若某个变量是 `X → M → Y` 中的 M，就不能把“政府使 M 上升”当成全文主结论，除非论文明确研究的是 M 本身且其企业经济含义足够强。

### 6. 精确碰撞审计与研究者既有工作的区分

对每个压缩后的 X/Y 做四层碰撞：

| 层次 | 必查内容 |
|---|---|
| 精确碰撞 | 同一 X、同一 Y、同一企业对象、相近制度和时间 |
| X 邻近 | 同一政府行为改变企业的其他决策 |
| Y 邻近 | 同一企业结果由其他政府行为解释 |
| 机制/制度邻近 | 同一传导机制在其他政府层级、产权类型或政策环境下的研究 |

同时检查中文论文、英文论文、工作论文、学位论文、会议论文和权威政策报告，并与用户既有论文逐项比较：研究问题、X、Y、样本、政策层级、识别和贡献是否真正不同。

碰撞状态只能使用：

- `OCCUPIED`：核心 X/Y 和问题已被直接研究；
- `ADJACENT`：问题相近，仍需说明新增边际；
- `OPEN-WITHIN-BOUNDARY`：在已声明检索边界内未定位到直接研究，且已有证据支持其重要性；
- `UNKNOWN`：检索或全文证据不足。

只有 `OPEN-WITHIN-BOUNDARY` 且空白成因可克服，才可能进入 `GO`；“搜索结果少”本身不能进入 `GO`。探索初筛未达到优先路径的 5—8 篇审计配额时，最多只能 `HOLD`。

### 7. 可行性、竞争性解释和决策门

按 `references/feasibility-identification-audit.md` 和 `references/competitive-predictions.md` 审计：

- X、Y、M 和控制变量的真实数据来源、字段状态和构造成本；
- 样本单位、时间范围、处理组/控制组、处理时点、处理强度和集群数量；
- 基准识别、关键假设、主要威胁、替代设计和最小可行样本；
- 至少两个能解释结果的竞争性解释，以及能区分它们的可观测预测；
- 主结果不显著、符号反向、平行趋势失败或仅在严格口径成立时，研究问题如何降级、回退或淘汰。

使用以下决策门：

- `GO`：大问题清楚；版图覆盖充分；空白及其成因有证据；核心 X/Y 单一明确；最小设计和证伪条件成立；用户确认进入研究计划；
- `HOLD`：问题有价值，但精确碰撞、全文证据、数据可得性、政策时点或识别仍有关键不确定性，必须写出下一项验证；
- `KILL`：直接重复、空白只是机制或换指标、数据无法获得、识别无法成立、Y 经济含义弱或贡献不足，记录淘汰理由。

## 对话交付格式

新论文选题的第一轮报告必须按以下顺序交付，不能从候选标题开头：

1. 我从既有论文中识别出的研究主线；
2. 用户现实观察背后的大问题和尚未解决的制度矛盾；
3. 已覆盖的研究版图（分支、代表性文献、共识、争议和边界）；
4. 空白清单及每个空白“为什么没有被做”的诊断；
5. 由证据推导的 3—5 个研究谜题，而非只给题目；
6. 每个谜题的候选政府行为 X、企业结果 Y、机制、碰撞状态和失败风险；
7. 推荐优先验证的 1—2 条路径，以及仍需补齐的证据；
8. 明确的 `GO / HOLD / KILL`，或说明为什么尚不能作决定。

每一部分都要区分“直接文献证据”“基于文献的合理推断”和“待验证假设”。除非用户明确要求立即落库，否则先在对话中完成这份研究发现报告；不要让用户通过连续纠正来替工具补齐基本研究地图。

## 必须遵守的质量护栏

逐候选题目读取 `references/quality-guardrails.md` 和 `references/exploration-and-gap-diagnosis.md`。核心要求包括：非简单两端拼接、非简单跨国或换样本复制、制度差异产生新预测、单向主线、政治与发表安全、与普通 CSSCI 目标匹配、可证伪。

同时遵守：

- 不捏造文献、DOI、样本量、数据字段、数据库结果或检索结果；
- 不把少量搜索结果、摘要或政策新闻冒充完整文献全景；
- 不把“没人研究”当作默认句式；
- 不把机制、异质性、交互项或政策含义误写成主研究问题；
- 不因用户提出宏大叙事就强行寻找一个不匹配的 X/Y；
- 不在没有最小可行设计和空白成因诊断的情况下确认题目；
- 不丢弃淘汰方向，必须记录证据、原因和日期。
