# Competitive explanations and falsification matrix

## 1. 解释对象

主解释和替代解释必须针对同一个结果，不要把“可能存在其他机制”当作完整的竞争性解释。

常用替代解释类别：

- 机制替代：结果由另一条行为渠道驱动；
- 测量替代：核心变量测到的是披露、规模或文本偏差；
- 遗漏变量：同期政策、地区趋势或企业选择同时影响 X 和 Y；
- 选择/碰撞：样本进入、政策试点或披露行为造成选择；
- 反向因果：Y 的变化促成政策实施或处理强度变化；
- 时间边界：提前反应、滞后反应或政策效果仅在特殊窗口出现；
- 竞争性政策：另一项改革同时改变结果。

```markdown
| 解释 | 核心机制 | 可区分预测 | 检验/测量 | 预期方向和不确定性 | 不支持条件 |
|---|---|---|---|---|---|
| 主解释 | | | | | |
| 替代解释 1 | | | | | |
| 替代解释 2 | | | | | |
```

## 3. 预测要求

每个预测必须指定：条件、观测对象、时间、预期模式、允许的不确定性、与替代解释不同之处。如果两个解释对所有可观察结果都给出相同预测，不能声称完成了机制区分。

至少写出：

- 一个支持主解释的预测；
- 一个会削弱主解释的结果；
- 一个能区分主解释和替代解释的预测；
- 必要时一个负向/安慰剂/伪处理控制。

## 4. 证伪条件

提前写清楚下列结果如何处理：

| 结果 | 默认处理 |
|---|---|
| 主结果不显著 | 回到问题重要性和测量审计，不自动换模型 |
| 系数反向 | 冻结结果，进入 `research-discovery` 分层诊断 |
| 处理前趋势失败 | 回到识别设计，不能只换基期或删除不利年份 |
| 仅一个 Y 口径显著 | 降低结论强度，检查测量差异 |
| 机制变量不响应 | 放弃该机制或改写理论，不把异质性冒充机制 |
| 仅少数子样本显著 | 判断是否为理论边界、统计功效或多重检验问题 |
