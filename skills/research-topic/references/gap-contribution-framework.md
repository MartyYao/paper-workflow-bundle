# Gap and contribution framework

## 1. 先区分三个对象

| 对象 | 含义 | 典型错误 |
|---|---|---|
| 研究问题 | 要解释的现象或因果关系 | 直接写成一个回归式 |
| 研究空白 | 文献在什么边界内仍不能解释 | 把“没有搜到”写成“没人做过” |
| 研究贡献 | 结果会更新哪一类知识 | 把新样本、新变量自动等同于贡献 |

## 2. 空白分类

### 事实空白

现象是否存在、方向是否稳定、影响范围是否未知。必须说明为什么确认该事实会改变已有判断，而不是只增加一个描述统计量。

### 机制空白

已有 X→Y 关系，但中间渠道未被区分。必须提出竞争性机制和可以区分它们的预测，不把机制变量显著就当作机制成立。

### 理论空白

已有理论在新制度条件下给出不同预测。必须写出制度差异如何改变行为约束、激励或资源配置，而不是只说“中国情境特殊”。

### 制度/外部有效性空白

已有结论尚未在重要制度环境中检验。中国样本只有在制度环境产生不同预测、边界条件或政策含义时才构成有价值的外部有效性研究。

### 测量或方法空白

已有指标存在系统性测量误差，或已有识别设计不能解决关键内生性。新指标/新方法必须服务于一个实质研究问题，不能成为论文的唯一卖点。

### 冲突空白

已有研究结论相反或依赖不同样本、制度和测量。先解释冲突来源，再提出能够区分解释的设计，不能挑选支持自己的论文。

## 3. 空白声明模板

```markdown
已有研究在【样本/制度/测量】下发现【共识结论】，并主要通过【机制/识别】解释。
但这些研究无法回答【明确的未解问题】，原因是【制度差异、机制未区分、测量限制或结论冲突】。
本研究在【新的条件】下检验【新的预测/机制/事实】，使用【数据与识别设计】。
如果结果成立，它将更新【具体文献、理论机制或政策判断】；如果结果不成立，仍将界定【理论或制度边界】。
```

## 4. 创新价值备忘录

每个候选题目都要分别写：

1. **理论价值**：改变哪个理论机制、边界条件或方向预测？
2. **经验价值**：确认、推翻或细化哪个重要事实？
3. **制度价值**：中国制度安排带来什么不可替代的信息？
4. **测量/数据价值**：新测量解决什么系统性误差？
5. **政策价值**：结果如何影响政策工具、资源配置或企业决策？
6. **失败结果价值**：不显著、反向或识别失败时，什么结论仍然成立？

贡献价值的核心测试：

> 如果这篇论文的主结果只是在已有结论上换一个城市、年份、指标或政策，现有文献的哪一条判断会被改变？

如果回答不出具体文献或判断，候选题目最多是 `HOLD`，不能 `GO`。

## 5. 中文公司金融适配

吸收旧版 `chinese-corporate-finance-topic-design` 的有效约束：

- X→Y 主链条尽量直接，复杂中介不能替代核心问题；
- 主回归的 Y 必须是可以独立理解的经济指标，交互项通常是机制或异质性，不是主问题；
- 故事保持一条主线，竞争性解释用于检验而不是写成骑墙叙事；
- 不主动承诺“能投什么期刊”，默认以普通 CSSCI 的研究成本和贡献上限为约束；
- 处理变量、因变量和机制的关系必须在文献矩阵中有出处。
