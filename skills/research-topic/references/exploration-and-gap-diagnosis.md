# 研究发现与空白成因诊断协议

本文件是 `research-topic` v0.2.0 的工作细则。它解决一个核心问题：选题工具必须先证明“这个研究空间的地图是什么”，再谈“哪里是空白”和“题目怎么做”。

## 一、三种模式的切换

### A. 探索模式

适用于“开始新论文”“找研究方向”“我只有一个现实观察”。

输出顺序固定为：

```text
研究者研究脊梁
→ 大问题重构
→ 研究空间分支
→ 分支文献地图
→ 分支空白与空白成因
→ 研究谜题
→ X/Y 压缩
→ 优先验证路径
```

探索模式的目标是扩大并组织研究空间，不能过早把一个未经查新的方向包装成“推荐题目”。

### B. 审计模式

适用于用户已经同时给出一个政府行为 X、一个企业层面 Y、行为主体、行为/政策时点和处理变异。仅给出政策领域、宏观背景、企业类型或候选标题，不满足进入审计模式的条件，仍须先做探索。审计模式至少要补齐：精确碰撞、X 邻近、Y 邻近、机制/制度邻近四层证据，以及“为什么已有研究没有把这个问题做完”的诊断。

### C. 决策模式

适用于已有多个候选方向。只比较有证据的候选；`UNKNOWN` 不能按“低风险”处理，而应单列为待查事项。

## 二、从宏大叙事到研究问题的拆解表

面对“经济转型”“K 型分化”“AI 红利没有普惠”“财政压力”“国企承担责任”等叙事，先填写：

| 层次 | 要回答的问题 | 合格产物 |
|---|---|---|
| 事实 | 具体发生了什么，哪一类企业受到影响？ | 可引用的事实和时间范围 |
| 制度矛盾 | 政府的目标、责任或权力边界发生了什么变化？ | 制度冲突，而不是价值判断 |
| 政府边际 | 政府做了哪个具体动作或改变了哪条制度？ | 政策、监管、财政、产权、信用或考核行为 |
| 企业边际 | 企业最直接改变了哪一个决策？ | 一个企业层面 Y |
| 因果命题 | 政府行为是否改变企业决策？ | 一个可估计的 X → Y |
| 机制 | 企业为什么改变该决策？ | 最小必要 M |

其中，“AI、高科技、房地产下行、K 型分化”通常是事实背景；“地方政府债务置换、国资监管考核、政府采购规则、分税/转移支付制度、国有资本收益上缴安排”等才可能成为核心 X。判断不能靠词语的宏大程度，而要看能否定位行为主体、时点和处理变异。

## 三、研究版图的分支和文献配额

### 1. 最低分支设计

新方向至少建立 4 个分支。优先从以下模板中选择与问题相关的分支，而不是机械地搜索一个完整句子：

1. **同 X，不同 Y**：同一政府行为已经影响了企业融资、投资、创新、就业、分红、并购或空间布局中的哪些结果？
2. **同 Y，不同 X**：同一企业结果已有哪几类政府解释？新政策是否只是换了名称？
3. **同 M，不同制度**：例如隐性担保、政策负担、资源配置、软预算约束、政府干预等机制在何种制度下成立？
4. **同现实问题，不同政府工具**：政府是通过财政、产权、监管、信用、采购、土地、考核还是公共服务影响企业？
5. **同政策，不同政府层级/产权**：中央、地方、国企、民企是否面临不同的处理边际？
6. **同结论，不同识别**：已有结论是相关性、政策评估、工具变量、自然实验还是描述性事实？

### 2. 每个分支的最低证据

采用两阶段配额。探索初筛阶段，每个分支至少收集 3 篇独立学术文献；进入优先路径审计阶段，再把相关分支扩展到 5—8 篇。代表性不是简单凑数，应尽量包含：

- 探索初筛：至少 1 篇中文和 1 篇英文（如果某一语言通道确实无法获得，记录限制），并在分支层面至少有 1 篇挑战/限定性研究；
- 优先路径审计：1—2 篇精确研究（若无，记录为 `0`，不能用邻近文献代替）；
- 2—3 篇核心邻近研究；
- 1 篇近期研究或工作论文；
- 1 篇提出不同结论、限制条件或识别批评的研究；
- 1 篇能说明制度背景或政府行为来源的权威资料（政策材料单列，不计入学术文献配额）。

如果探索初筛一个分支只能找到 1—2 篇文章，先标为 `UNKNOWN`，除非已经完成同义词、制度名称、英文表达、引用追踪和相关结果变量的扩展搜索；如果优先路径无法扩展到 5—8 篇，应保留 `HOLD`，不能把文献不足包装成开放空白。

### 3. 查询矩阵

每个分支至少使用四类查询：

| 查询类 | 句式 | 用途 |
|---|---|---|
| 精确 | `[政府行为] AND [企业结果] AND [中国/国企/地方]` | 查直接碰撞 |
| 政府展开 | `[政策制度] AND [firm behavior / corporate finance]` | 查政策的其他企业后果 |
| 结果展开 | `[企业结果] AND [government intervention / fiscal pressure / state ownership]` | 查 Y 的已有政府解释 |
| 机制展开 | `[mechanism] AND [firm outcome] AND [institution]` | 查理论和制度邻近 |

中英文不要逐字翻译后只搜一次。对政府行为、国企、政策负担、隐性担保、分配、企业责任等词分别建立同义词和制度词表；英文检索加入 `state-owned enterprise`, `local government`, `government intervention`, `policy burden`, `soft budget constraint`, `implicit guarantee`, `corporate behavior`, `firm-level` 等可能表达，但必须根据返回文献迭代词表。

## 四、文献证据编码

每一篇进入核心矩阵的文献至少记录：

```text
作者/年份/期刊或工作论文
标题、DOI/URL、全文状态
研究问题
政府行为或制度
X、Y、M
企业层级和样本
识别策略与主要假设
核心结论
结论边界/限制
证据角色：精确、邻近、支持、挑战、限定、背景
与当前问题的关系
```

`文献证据台账.csv` 还必须用机器可读字段统一记录版图状态：

```text
branch_id,relation_type,search_status,language,source,search_date,query,
title,authors,year,journal,doi,firm_level,x_concept,y_concept,mechanism,
sample,identification,claim_supported,claim_challenged,screen_status,
fulltext_status,exclusion_reason,notes
```

其中 `relation_type` 使用 `DIRECT`、`ADJACENT-X`、`ADJACENT-Y`、`ADJACENT-M`、`BACKGROUND`；`search_status` 使用 `LOCATED`、`NOT-LOCATED-WITHIN-BOUNDARY`、`UNKNOWN`。`精确空白`不是台账状态，而是根据 `relation_type=DIRECT` 的检索结果和覆盖边界在报告中作出的判断。

“作者认为相关”“摘要提到政策”“网页标题含有关键词”不等于该文研究了同一 X/Y。必须区分：

- `DIRECT`：X、Y 和企业层级问题基本相同；
- `ADJACENT-X`：政府行为相同，Y 不同；
- `ADJACENT-Y`：Y 相同，政府行为不同；
- `ADJACENT-M`：机制相同，制度或样本不同；
- `BACKGROUND`：只说明政策或现实背景。

`relation_type` 描述文献与问题的关系，`search_status` 描述检索状态，`evidence_role` 描述该文献在论证中的证据作用；三者不能混用。

当全文不可得时，书目信息可以纳入检索记录，但不能用来支撑精确结论；将全文状态记为 `metadata-only` 并降低证据等级。

## 五、空白成因诊断表

每个分支都要填写下表，不能只填写“国内研究不足”：

| 字段 | 诊断问题 |
|---|---|
| 已有共识 | 多篇研究共同支持的结论是什么？ |
| 未决问题 | 哪个重要问题没有被解释或结论不一致？ |
| 精确空白 | X/Y/制度/企业层级是否确实未定位到直接研究？ |
| 空白类型 | 事实、机制、制度、测量、方法、外部有效性、冲突或其他？ |
| 空白成因 | 数据、制度时点、识别、概念、聚合层级、结果变量弱、文献拥挤或死胡同？ |
| 成因证据 | 哪篇文献、政策事实、数据试采或方法分析支持该判断？ |
| 是否可克服 | 通过新数据、新政策、重新定义或新识别能否解决？ |
| 最小研究问题 | 只保留一个 X 和一个 Y，最小可回答的问题是什么？ |
| 失败处理 | 若障碍无法克服，HOLD 还是 KILL，理由是什么？ |

### 空白诊断的几个硬规则

1. **数据难不自动等于创新**：只有数据障碍与重要经济问题同时存在，且有现实可行的替代数据，才可能形成数据贡献。
2. **政策新不自动等于因果识别**：政策刚出台可能是制度空白，但没有处理后期、对照组或执行差异时，只能 `HOLD`。
3. **宏观空白不自动等于企业贡献**：地区层面的财政压力或产业增长不能直接推出企业行为，必须解释企业暴露和传导。
4. **机制未研究不自动等于主问题**：如果“国企承担社会责任”只是 X 影响企业结果的传导渠道，就不能把它单独包装为 Y。
5. **换指标不自动等于新题目**：若新 Y 只是旧 Y 的同义测量，状态通常为 `ADJACENT` 或 `OCCUPIED`。
6. **找不到文献不等于文献不存在**：未完成引用追踪、作者/制度词扩展、中文/英文交叉和工作论文搜索前，只能写 `UNKNOWN`。
7. **空白成因必须分主次**：每个分支写明一个主要成因、可选的次要成因、证据类型（直接证据/合理推断/待验证假设）和证据等级（高/中/低）。数据成因必须附数据试采或明确字段核验；制度/时点成因必须说明处理后期和对照；识别成因必须指出具体的反向因果、选择或遗漏变量路径。

## 六、从空白推导研究谜题的六种变换

完成“已知—未知—成因”后，使用变换生成研究谜题。每条变换都必须落回企业层面：

1. **从政府目标到企业承接边际**：政策声称解决某类公共问题，企业实际改变哪一个财务或投资决策？
2. **从同一政策的平均效应到政府边界**：政策影响国企和民企的方式是否不同，政府行为是否改变了企业的权利义务边界？
3. **从宏观状态到可识别政府工具**：把“财政压力/房地产下行/技术革命”转换成可定位的财政、监管、产权、信用或考核动作。
4. **从政府索取到企业资源配置**：政府取得收益、要求责任或提供信用后，企业在哪一个单一资源配置边际上调整？
5. **从政策目标到未预期企业后果**：研究政策的既定目标已经拥挤时，查找企业融资、投资、分红、创新质量、风险承担等未被解释的后果。
6. **从制度差异到识别差异**：中央/地方、国企/民企、行业监管或执行强度的差异能否产生可检验预测，而不是只做异质性表格。

每个谜题都必须使用以下卡片：

```markdown
### 谜题编号：
- 大问题：
- 文献事实：
- 文献证据台账 record_id：
- 不能解释之处：
- 未决问题证据 record_id：
- 政府行为 X：主体、层级、时点、处理变异
- 企业结果 Y：单一结果及经济含义
- 最小机制 M：
- 精确/邻近文献状态：
- 主要空白成因：
- 成因证据类型/等级：
- 为什么值得做：
- 为什么可能做不成：
- 若结果为正/不显著/反向，分别更新什么：
- 下一项最小验证：
```

## 七、对话中的研究启发报告

第一轮报告不以题目列表开头，建议采用下列顺序：

1. 研究者的研究主线和新问题的连续性；
2. 大问题重构：现实事实、制度矛盾、政府选择和企业后果；
3. 版图表：至少 4 个分支，每个分支给出代表性文献、共识、边界和检索状态；
4. 空白—成因表：明确哪些是真空白、哪些是未知、哪些是死胡同；
5. 3—5 张谜题卡片；
6. X/Y 压缩表和精确碰撞状态；
7. 推荐下一步：优先补哪一条文献证据或做哪一个数据试采；
8. 当前决策：`GO / HOLD / KILL`，并说明证据等级。

报告中每项判断加上以下标签之一：

- `[文献直接证据]`
- `[基于文献的合理推断]`
- `[待验证假设]`
- `[数据/识别风险]`

这样做的目的不是增加格式，而是防止把研究者的直觉、助手的推断和已经发表的事实混写成同一个结论。

## 八、最低检索日志

检索边界文件至少记录：

```text
检索日期：
中文平台及权限：
英文平台及权限：
学科和年份范围：
同义词/制度词表：
每个分支的查询式：
引用追踪方式：
纳入和排除标准：
全文不可得的条目：
已经覆盖的研究空间：
仍然未知的研究空间：
```

如果没有达到探索初筛配额，报告不得说“研究较少”或“文献空白”，只能说“当前检索覆盖不足，暂列 `UNKNOWN`”。如果没有达到优先路径审计配额，该路径最多 `HOLD`。
