# 实证表格格式规范

> 日期: 2026-07-11
> 来源: Marty 论文1 实证审查反馈
> 关联: paper-workflow 阶段 5

## 核心原则

**实证部分的产出是可以直接插入论文的表格，不是草稿摘要。** 审稿人看到「省略了控制变量」或「未报告固定效应」，直接质疑透明度。

## 必须遵守的 12 条规则

### 1. 不省略控制变量

所有回归表格必须列出全部控制变量的系数和标准误。即使 15 个控制变量拉长了表格，也比「省略」好——可以拆成两张表，但不能只报 post 系数。

❌ `esttab ... keep(post)`
✅ `esttab ... keep(post Size Lev ROA SOE ...)`

### 2. 主回归三列制

每个被解释变量至少跑三列：
- (1) 仅 post，无控制变量
- (2) post + 企业层面控制变量
- (3) post + 企业 + 省级控制变量

这条规则适用于基准回归，不强制稳健性和异质性。

### 3. V1/V2 分表

如果被解释变量有多个版本（如补贴口径 V1 标准版 / V2 严格版），分成两张独立表格。9 列表格（3 列 × 3 DV）在社科论文中勉强可接受，但 V1+V2 合并的 18 列表格不可接受。

### 4. 固定效应标注

每列表格下方标注：
- 是否包含企业固定效应
- 是否包含年份固定效应
- 标准误聚类层级（省份/行业/企业）

格式示例：
```
注：括号内为 t 值；所有模型包含企业固定效应和年份固定效应；
标准误在省份层面聚类（N=31）。* p<0.10, ** p<0.05, *** p<0.01。
```

### 5. 样本量与 Adj R²

每列必须报告观测值数量 N 和调整后 R²（Adjusted R²）。Within R² 在固定效应模型中更准确但学界习惯报告 overall Adj R²。

### 6. 描述统计含全部变量

Table 1 必须包含：
- 被解释变量（主回归中出现的所有 DV）
- 处理变量
- 全部企业控制变量
- 全部省级控制变量
- 机制变量
- 经济后果变量（如有）

保留三位小数，报告 N / Mean / SD / Min / P50 / Max。

### 7. 相关性分析必须出现

放在描述统计之后、主回归之前。使用 pairwise 相关（pwcorr），标注显著性星号。

⚠️ 不用 `corr`（listwise deletion 会在缺失值不同的变量间归零）。

### 8. 回归执行顺序（严格）

```
描述统计 + 相关性分析
  → 主回归 (V1 → V2)
    → 机制检验 (紧跟主回归)
      → 稳健性检验 (竞争政策 / 词频 / PSM / 安慰剂 / Leave-one-out)
        → 内生性检验 (IV / Heckman)
          → 异质性分析 (产权 / 市场化 / SRDI / 处理强度)
            → 经济后果
```

机制必须在异质性之前——审稿人的逻辑是「先证明机制存在，再看谁更受益」。

### 9. 稳健性检验独立成表

竞争性政策、政府数字词频、PSM、安慰剂检验各自独立成表，不要拼成一列「是否包含」的复选框。

### 10. Leave-One-Out 规范

逐省（或逐城市/逐行业）剔除后重新回归，报告 post 系数的范围（最小值~最大值）和全部 p<0.05 的比例。说明无单一单位驱动全部结果。

### 11. 安慰剂检验规范

随机分配处理组 500-1000 次，绘制安慰剂系数分布图。报告真实系数在分布中的分位数位置。

### 12. 内生性检验控制变量一致

IV 第一阶段和第二阶段必须包含与主回归完全相同的控制变量集合，不增减。

## CSV/TeX 输出规范

`esttab` 使用以下选项：

```
esttab m1 m2 m3 using "table_name.csv", replace ///
    star(* 0.10 ** 0.05 *** 0.01) ///
    stats(N r2_a, fmt(%9.0f %9.3f) labels("N" "Adj R²")) ///
    order(...控制变量列表...)
```

## 常见错误（2026-07-11 真实审查记录）

| 错误 | 被纠正为 |
|------|---------|
| 主回归表中放入竞争性政策控制变量 | 移至稳健性检验独立表 |
| 表格仅报告 post 系数 | 列出全部控制变量 |
| 未标注固定效应和聚类 | 表注中补充 |
| 主回归仅一列「全控制」 | 改为三列逐步回归 |
| V1+V2 合并为一张 6 列表格 | V1、V2 拆为两张 3 列×3 DV 表格 |
| Table 1 缺省级控制变量 | 补全 |
| 无相关性分析 | 补 pwcorr |
| 机制检验放在异质性之后 | 移至主回归之后、异质性之前 |
