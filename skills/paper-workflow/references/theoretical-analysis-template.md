# 理论分析与研究假设模板

paper-workflow 阶段 2 专用。A 主线（检查清单）+ B 可选（完整框架生成）。

---

## A 主线：质量检查清单（强制执行）

阶段 2 完成前，逐条确认：

### 制度背景
- [ ] 处理变量的制度来源有明确政策文件引用
- [ ] 推行时点和地区差异有详细描述
- [ ] 制度细节足以支撑识别策略（为什么某些地区先推行、某些后推行或未推行？）

### 理论框架
- [ ] 有一条清晰的理论透镜（信息不对称/委托代理/交易成本/资源依赖/信号/制度理论等）
- [ ] X → M → Y 的逻辑链每步有文献支撑或理论推导
- [ ] 不选中框架的理由有记录（为什么排除另外几个候选？）

### 假设提出
- [ ] 每条假设有理论依据（非"已有研究"的模糊引用）
- [ ] 有明确方向预测（正向/负向/非线性）
- [ ] 可证伪：什么实证结果算"不支持假设"？
- [ ] 不与已有文献已知结论冲突（冲突时说明了原因）

---

## B 可选：完整框架生成

当用户选择完整框架时，按以下结构生成 `03-理论/理论推演.md`：

### 1. 制度背景
处理变量的制度渊源 → 推行时点 → 地区差异 → 与识别策略的关联

### 2. 理论框架选择
列出至少 3 个候选理论透镜 → 逐一分析适用性 → 选定并说明理由

### 3. 机制推演
对每条假设：
- X → M1 → M2 → Y 完整逻辑链
- 每步的文献支撑
- 方向预测及理由

### 4. 竞争性解释排除
- 反向因果检查
- 遗漏变量检查（同时期其他政策？）
- 替代机制检查（不经过本机制也能解释 Y？）

### 5. 研究假设
H1/H2/H3 的正式表述，满足 A 主线全部检查项。

## 候选理论透镜速查

| 理论 | 核心逻辑 | 适用场景举例 |
|------|---------|-------------|
| 信息不对称理论 | X → 信息透明度 ↑ → 识别/匹配效率 ↑ → Y | 数字政府 → 补贴识别准确度 |
| 委托代理理论 | X → 监督成本 ↓ → 代理人行为改变 → Y | 数字政府 → 官员自由裁量权 ↓ |
| 交易成本理论 | X → 流程标准化 → 交易成本 ↓ → Y | 数字政府 → 企业审批成本 ↓ |
| 资源依赖理论 | X → 资源获取渠道改变 → 企业行为调整 → Y | 数字政府 → 企业信息获取能力 ↑ |
| 信号理论 | X 作为信号 → 改变外界预期 → 行为改变 → Y | 大数据局成立 → 投资者关注 |
| 制度理论 | X → 正式/非正式制度变迁 → 组织行为趋同/分化 → Y | 数字政府 → 制度环境改善 |
